📝 Online Feedback & Survey System

📌 Project Overview

The Online Feedback & Survey System is a simple web-based application that allows users to submit their feedback and rate their experience. It provides an easy and user-friendly interface for collecting feedback online.

Live Project Link 
https://jananijoy15.github.io/Online-Feedback-Survey-System/

✨ Features

- 👤 User name and email input
- ⭐ Service rating system
- 📊 Experience selection
- 💬 Feedback submission
- ✅ Form validation using JavaScript
- 📱 Mobile-friendly responsive design
- 🎨 Clean and professional user interface
- ✔️ Displays a confirmation message after submission

🛠️ Technologies Used

- HTML5 – Structure of the web page
- CSS3 – Styling and responsive design
- JavaScript – Form validation and interactive functionality

⚙️ How It Works

1. User enters their name and email.
2. User selects a service rating.
3. User selects their overall experience.
4. User enters their feedback.
5. JavaScript validates all required fields.
6. After successful validation, the feedback is submitted.
7. A thank-you message is displayed to the user.

🎯 Objective

The main objective of this project is to demonstrate how HTML, CSS, and JavaScript can be combined to create an interactive online feedback system with client-side form validation.
